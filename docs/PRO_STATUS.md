نسخة ما قبل التطوير: فرع `backup-pre-pro-2026-10-30`.

## أين أرى كل شيء في التطبيق
| الميزة | المكان |
|---|---|
| قوائم المتابعة (20 شخصية/جهة + 6 قضايا) | تبويب «المتابعة» ← اضغط أي اسم |
| نوع الرصد (مباشر / نقل عن مصدر / إدخال يدوي / متعذّر) | داخل صفحة الشخصية، وشارة على كل خبر |
| حالات التحقق الخمس + أقدم نشر رصدته المنظومة | شارة على كل خبر، والتفاصيل عند فتحه |
| تصنيف الحشد (قرار/بيان/تصريح/خبر/تحليل/دولي) | تبويب «الحشد الشعبي» |
| لوحة الأداء + العينة المرجعية | الأدوات ← لوحة الأداء |
| التقارير الصباحية (HTML/نص/PDF) | الأدوات ← التقارير الصباحية (وتصل PDF بالخاص) |
| صندوق المحررين (إدخال يدوي/حكم) | بوت تلغرام بالخاص؛ الشرح في الأدوات ← صندوق المحررين |
| التلفزيون (تجريبي) | الأدوات ← التلفزيون |

## الحالة الصريحة
| القدرة | الحالة | ملاحظات |
|---|---|---|
| نسخ احتياطي مستقل + استعادة تلقائية | يعمل فعلياً | لقطة كل 30 د على Release `db-backup`، أرشيف يومي دائم `archive-YYYY-MM`. اختبار استعادة ناجح 30/10 (9494/9494 مادة) |
| سبب فقدان الأرشيف | مُعالج | تغيير قائمة مسارات الكاش يغيّر نسخته فتضيع القاعدة. القائمة مجمّدة + استعادة من Release |
| سجل الشخصيات والجهات (20) | يعمل فعلياً | `config/follow.json`؛ 12 قناة تلغرام رسمية مؤكدة مرصودة مباشرة |
| رصد فيسبوك مباشرة | غير متاح مجاناً/رسمياً | يحتاج موافقة Meta (Page Public Content Access) + توثيق شركة؛ الكشط مخالف. البديل: القنوات والمواقع الرسمية + النقل + الإدخال اليدوي |
| رصد X مباشرة | يحتاج اشتراك | الوصول الرسمي مدفوع |
| بحث Google News عن الشخصيات | يعمل فعلياً | مسار مساعد، ليس تغطية كاملة أو فورية |
| الإدخال اليدوي عبر البوت | يعمل فعلياً | المحررون = مشرفو القناة |
| تنبيهات المتابعة بالخاص + منع التكرار | يعمل فعلياً | حدث واحد = تنبيه واحد، وتحديث واحد إذا صار عاجلاً؛ ملخص 8 صباحاً |
| حالات التحقق الخمس | يعمل فعلياً (آلي) | «ثبت عدم صحته» بحكم محرر فقط |
| مصادر فارسية وتركية + ترجمة | يعمل فعلياً | ترجمة آلية عبر الإنكليزية مع الأصل |
| التقرير الصباحي | يعمل فعلياً | 7 ص بغداد؛ PDF بخط عربي سليم |
| لوحة الأداء والعينة المرجعية | يعمل فعلياً | العينة: 20 خبراً من «أبرز أخبار العراق» Google News ضمن نافذة الأرشيف |
| التلفزيون | تجربة محدودة | مقاطع ≤3 د من 6 قنوات على تلغرام؛ تفريغ آلي بلا نسب لمتحدث |
| بث تلفزيوني مستمر | يحتاج موافقة/خادم | غير مقترح الآن |

## الحدود المجانية
Actions للمستودع العام بلا رسوم دقائق؛ كاش Actions 10GB (تُحذف الأقدم وتنتهي بعد 7 أيام بلا استخدام)؛ ملف Release حتى 2GB؛ موقع Pages 1GB. النسخ على Releases عامة لأن المستودع عام (أخبار منشورة أصلاً، بلا أسرار).
