# هوبي عاجل — نسخة الهاتف

تطبيق هاتف بسيط يعرض أخبار العراق المهمة خلال آخر 10 دقائق، آخر ساعة، واليوم، مع حالة التحقق لكل خبر.
GitHub يجمع الأخبار كل 10 دقائق تقريباً من 16 قناة تلغرام وخلاصات RSS، وينشر التطبيق على GitHub Pages.
لا أسرار ولا اشتراكات. المستودع يجب أن يكون **عاماً** حتى تبقى دقائق التشغيل مجانية (144 جولة يومياً).

## التشغيل لأول مرة
1. ارفع هذا المجلد إلى مستودع عام اسمه `hobi-ajel`.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. Actions ← hobi-ajel ← **Run workflow** مرة واحدة. بعدها يعمل وحده كل 10 دقائق.
4. افتح `https://<اسم-حسابك>.github.io/hobi-ajel/` في كروم على الأندرويد ← القائمة ← **تثبيت التطبيق**.

## ملف APK لتلفونات محددة
1. افتح pwabuilder.com وأدخل رابط التطبيق.
2. Package for stores ← Android ← Download.
3. أرسل ملف APK للتلفونات التي تختارها، وثبّته (يطلب السماح بتثبيت التطبيقات من مصادر غير معروفة).

## رمز الدخول
التطبيق يطلب رمزاً عند أول فتح. لتغييره: `python3 tools/set_code.py 123456` ثم ارفع التغيير.
الرمز حماية خفيفة تمنع الفضوليين، وليس تشفيراً: محتوى التطبيق أخبار عامة أصلاً.

## تعديل المصادر
`config/sources.json`. لا تضف قنوات جهات مصنّفة منظمات إرهابية.
